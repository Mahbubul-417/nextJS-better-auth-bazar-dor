# BazarDor

BazarDor is a Bengali-language web application that helps users explore daily market prices in Bangladesh. Users can browse products, compare current prices with previous prices, and track price changes to make informed shopping decisions.

## Technologies Used

- **Next.js** – React framework for building the web application
- **React** – Building interactive user interfaces
- **TypeScript** – Type-safe JavaScript development
- **Tailwind CSS** – Responsive and modern UI styling
- **Better Auth** – User authentication
- **MongoDB** – Database for user information
- **React Toastify** – Displaying success and error notifications
- **REST API** – Fetching product prices and category data

## Key Features

1. **Daily Market Prices** – Browse product prices and market information.
2. **Price Change Tracking** – Identify products whose prices are increasing or decreasing compared with previous prices.
3. **Product Categories** – Explore products organized into different categories.
4. **User Authentication** – Create an account and sign in securely using the available authentication methods.
5. **Profile Management** – Update your profile name and manage your account.
